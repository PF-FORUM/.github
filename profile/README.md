# ПФ-Форум

🏭 Производственные сервисы, автоматизация и документация ПФ-Форум.

Рабочее пространство программных проектов ПФ-Форум. Основные направления — производственные инструменты, автоматизация, обучение и сопровождение систем.

## 🧭 Направления

| Направление | Назначение |
|---|---|
| 🛠️ Производственные инструменты | Программные средства для работы с инструментом и производственными данными. |
| 🤖 Автоматизация | Боты и сервисы для рабочих процессов. |
| 📘 Документация | Материалы для операторов и разработчиков. |
| 🎓 Обучение | Платформа и материалы для обучения. |
| 🗄️ Сопровождение | Служебные сценарии, работа с данными и резервное копирование. |

## 🔄 Как устроена работа

1. Выбрать рабочий проект и прочитать его README и инструкции.
2. Уточнить актуальное состояние задачи и необходимые доступы.
3. Внести изменение в соответствии с правилами проекта.
4. Выполнить проверки и обновить связанную документацию.
5. Выполнить развёртывание по порядку, установленному для проекта.

## 📌 О материалах

Открытая документация операторов находится в архиве. Рабочие инструкции, доступы и текущее состояние сервисов проверяются во внутренних проектах.

Часть проектов доступна только участникам организации. Инструкции запуска,
требования и ограничения проверяйте в README выбранного репозитория.
